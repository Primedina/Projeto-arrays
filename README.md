  <h1>BURGUER</h1>
  <h2>Trabalhando com array </h2>


<p>Esse projeto é para mostrar alguns métodos que podem ser trabalhados no array com javaScript. </p>
<p>Segue informações de cada método para que serve e como foi utilizado no projeto.</p>

<h2>FOREACH</h2>
<p>Serve para iterar cada elemento do array começando do primerio e indo até o último item do array. </p>
<p>Nesse caso mostrou todas as opções de hamburguer que tinha no array.</p>
<img src="assets/forEach.png" width="800" >

<h2>MAP</h2>
<p>Cria um novo array com a mesma quantidade de itens do array original , alterando alguma informação ou 
acrescentado um novo campo , mais a quantidade de itens do array continua a mesma.</p>
<p>Nesse caso foi feito um desconto de 10% nos valores de todos os produtos.</p>
<img src="assets/map.png" width="800" >

<h2>REDUCE</h2>
<p>Reduz o array a apenas um item.</p>
<p>Nesse caso foi feita a soma do preço dos hamburgueres e exibido na tela o valor.</p>
<img src="assets/reduce.png" width="800" >

<h2>FILTER</h2>
<p>Serve para filtar itens de um array.</p>
<p>Nesse caso filtrou e mostrou apenas os produtos veganos.</p>
<img src="assets/filter.png" width="800" >
